# FX Learning Lab

A static English-language course on forex market mechanics and risk. Includes five illustrated lessons, five interactive quizzes and an educational risk-budget calculator.

## Local preview

Run `python3 -m http.server 8000` from the repository root and visit http://localhost:8000/. The custom 404 page uses the GitHub Pages project path.

## GitHub Pages

Publish from `main` and `/(root)` in Settings → Pages. HTML, CSS, JavaScript and diagrams are served directly. Quizzes and calculator inputs are processed in the browser. The site includes no broker referral links, signup forms, payments or analytics.
